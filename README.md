# Movie App 🎬

A full-stack movie application built as part of my college coursework
at South East Technological University.

The project combines a React frontend with a Node.js and Express
backend, using MongoDB to store user accounts.

## Features

- Movie browsing interface.
- API routes for movies and actors.
- User registration and login.
- Password validation and hashing.
- JWT authentication for protected movie routes.

## Technologies

React · JavaScript · Node.js · Express · MongoDB · Mongoose · JWT · bcrypt

## Project structure

- `react-movies/` — React frontend.
- `movies-api/` — Express API, authentication and database code.
